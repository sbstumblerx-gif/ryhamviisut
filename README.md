# Ryhämviisut Hub

Nyt teemme Ryhämviisut-kotisivun. sinne tulee alustavasti etusivulle napit "kilpailut" "tilastot" "artistit" "musiikki" "äänestä" "osallistu"

asetuksiin tulee suoraan reitti adminiksi pääsyyn. kirjoittamalla asetusten tekstikenttään Valkkuonsöpö321 pääsee adminiksi ja saat oikeuden muokata kappaleita, artisteja, tuloksia ja pisteitä.

kilpailut sivulle admin lisää vuosiluvut kuten 2025 2026.... ne järjestetään aina suurimmasta luvusta pienimpään

niitä klikkaamalla näet taas siihen kuuluneet osuudet
osuuksia. voit lisätä osioita adminina ja kaikki mahdolliset on:

Artistijulkistus
Esittely
Karsinta
Finaali

Artistijulkistus osioon listataan artistien nimet ja lisätään upotettavan youtube vdeon linkki

esittelyyn lisätään artistien nimet kappaleineen ja upotetaan linkillä yt video tapahtumasta

Karsintaan lisätään kilpailevien artistien nimet kappaleineen ja jokaiselle määritellään saadut yleisöpisteet. sitten tulee raadit joka on se monimutkaisin osuus. 

Lisää raati: aseta raadille nimi
aseta kilpailijat raadin valitsemaan järjestykseen ja nimeä jokaiselle pistemäärä. tämä määrä lisääntyy yleisöäänten joukkoon. sivulla näkyy nämä tulokset. lopuksi jokaiselle määritetään "eteni finaaliin" tai "karsiutui"
